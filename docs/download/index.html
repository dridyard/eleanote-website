Installing on a Mac

Open the downloaded Eleanote-0.6.0.dmg file, then drag the Eleanote icon onto the Applications folder shown beside it. Open Eleanote from your Applications folder, and it will walk you through the two permissions macOS requires — microphone access so it can hear the visit, and accessibility access so it can type your note into your EMR.

Eleanote is code-signed and notarized by Apple under Eleanote LLC, so it opens with no security warning. If your Mac ever says the app is from an unidentified developer or is damaged, the file didn’t come from us — delete it and download again from this page.

Not sure which Mac you have? Click the Apple menu in the top-left corner and choose About This Mac. The Chip line should say Apple M1 or later.

Trouble installing on either platform? Email support@eleanote.ai and we’ll help you get set up.
